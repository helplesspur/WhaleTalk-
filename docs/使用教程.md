# 使用教程

> 适用于 WhaleTalk v0.1.0 及后续版本（Windows）。名字对不上时，以软件界面为准。

## 一、它能做什么

连接你的 B 站或抖音直播间，实时读取进房、弹幕、礼物、上舰/粉丝团、醒目留言（SC）、关注、点赞，
交给 Qoder 大模型生成回复（也可以只用模板），再用本机 GPT-SoVITS 合成语音播放：

| 事件 | 默认反应 |
|---|---|
| 进房 | “欢迎小王、阿花和新朋友来到直播间！”（短时间内多人合并成一句） |
| 弹幕 | AI 针对内容回复 |
| 礼物 | “谢谢老板甲的人气票……”（连击合并成一次） |
| 上舰 | 隆重感谢上船 |
| 醒目留言 | 先感谢，再回应留言内容 |
| 关注 / 点赞 | 简短感谢（点赞默认关闭） |

另外：Live2D 皮套（自动呼吸眨眼、对口型、按情绪换表情、头顶气泡），点歌，AI 游戏（可互动 / 单人），
OBS 歌单、字幕与游戏面板。

## 二、文件说明

| 文件 | 说明 |
|---|---|
| `WhaleTalk.exe` | 主程序，双击运行 |
| `qoder_login.bat` | 登录 Qoder CLI（AI 回复要用） |
| `config.json` | 设置文件，首次运行自动生成，**含登录信息，不要外传** |
| `logs/app.log` | 程序日志 |
| `logs/gsv_engine.log` | 由本程序启动的 GPT-SoVITS 引擎日志 |
| `qoder_workdir/` | Qoder 会话工作目录（空目录，不用管） |

## 三、第一次使用

1. **登录 Qoder**：双击 `qoder_login.bat`，浏览器里点确认。
   不想用 Qoder：在【AI 设置】切到“OpenAI 兼容 API”，填地址、模型名、Key。
2. **启动**：双击 `WhaleTalk.exe`，会打开一个**独立应用窗口**（内嵌 WebView2，没有地址栏；
   首次约 5 秒）。不会弹黑色控制台窗口，日志在 `logs/app.log`；系统缺 WebView2 时会自动退回 Edge 窗口。
   默认**什么都不自动开始**（不连接、不启动引擎、不放歌、不开游戏、不计时）；
   点【控制台】顶部卡片里的 **「开始」**，才会按你的设置启动。想打开就自动开始，勾上
   「打开软件时自动开始」。
3. **设置音色**（否则没有声音）：
   - GPT-SoVITS 目录、参考音频（3~10 秒干净人声）、参考音频文本（一字不差）
   - 没有自己的模型就用默认预训练权重；自己训练的模型放进 `GPT_weights*` / `SoVITS_weights*` 后点“刷新列表”
   - 点【试听】确认声音
4. **登录 B 站**（强烈建议）：【直播间 / 登录】→【扫码登录】。
   不登录也能收弹幕，但观众名字会被打码，AI 叫不出名字。
   播抖音的话跳过这步：在弹幕来源里选“抖音直播”，在自动打开的浏览器窗口里登录抖音。
5. **测试**：【控制台】右下角“模拟测试”，不需要真实观众就能听效果。

## 四、界面

### 控制台
- **开播总开关**（最上面一张卡）：点「开始」按设置启动连接直播间 / 语音引擎 / 自动歌单 / 游戏轮换；
  点「停止」会断开直播、停掉音乐和当前游戏，设置保持不变。旁边勾「打开软件时自动开始」可恢复开机即连。
  卡片上会写「将启动：…」，一眼看出这一下会启动哪些东西。
- 顶部：直播间状态、平台账号、AI、语音引擎、是否暂停
- 按钮：连接/断开、暂停/恢复、跳过当前语音、清空队列
- 左栏：直播间消息（灰色 = 被跳过，后面写了原因）
- 右栏：AI 回复（内容、来源、耗时、表情）
- 手动发言：“直接念” / “让 AI 说”

### 本场数据（控制台中间一排）
- **Token 用量**：本场调用 AI 累计的 token 数，数字前面的文字可以自己改（下方输入框）。
  AI 后端返回了用量就按真实值算；没返回（例如某些 CLI）就按字数估算，数字前会标 `≈`，
  鼠标下方的小字会写明输入 / 输出 / 调用次数。
- **本场已直播时长**：连上直播间开始计时，断开暂停，重连继续累加；不是软件运行时长。
- **本场礼物**：本次运行累计的礼物件数与总价值（`value`，B 站按金瓜子折算、抖音按抖币价格表），
  下面是逐条记录（时间、观众、礼物 ×数量、价值），免费礼物标“免费”。
- 点“重置本场”会清零这三项统计（不影响积分榜、不会重连、不会清空聊天记录）。
- **显示到直播画面**：【OBS 字幕】页最下方「直播画面 · 本场数据」，把 `http://127.0.0.1:8787/stats`
  加为浏览器源（透明背景，建议 520×280）。同一页可以改标题、位置、字号、显示项和礼物记录条数。

### 抖音直播模式（【直播间 / 登录】→ 弹幕来源）
抖音的弹幕接口需要签名，纯代码对接很容易失效。所以这里用浏览器自己打开直播间，
再把页面里的消息读出来，不需要抖音开放平台账号。

1. 【直播间 / 登录】→ 弹幕来源选“抖音直播”
2. 填直播间链接或房间号（`https://live.douyin.com/123456789` 里那串数字）
3. 点“保存并连接” → 会弹出一个独立的浏览器窗口（Edge / Chrome）打开你的直播间
4. **第一次请在窗口里登录抖音**，之后会记住（数据存在程序目录的 `douyin_profile`）
5. 窗口里能看到弹幕滚动了，软件就会开始念；【抖音直播间】卡片下方有“抓取状态”和原始消息预览

- 抓取方式：`浏览器抓取（默认）`；也可以选 `外部工具转发`，此时不打开浏览器，
  由别的弹幕工具把事件发到 `POST http://127.0.0.1:8787/api/douyin/ingest`
  （要带请求头 `X-BVB: 1`，JSON 格式）或 `ws://127.0.0.1:8787/ingest/douyin`（字段见界面上的说明）。
- 礼物价格表：每行 `礼物名=抖币`，用来判断付费礼物和“最低价值”（10 抖币 = 1 元）。
  没写价格的礼物按免费礼物处理（可在回复规则里选择是否感谢免费礼物）。
- 抖音的“加入粉丝团”会归到“上舰 / 粉丝团”这一类事件，模板变量 `{guard}` 是“粉丝团”。
- 点歌的礼物名默认是 B 站的（小花花 / 人气票），播抖音时到【点歌】里改成抖音礼物（如小心心）。
- 浏览器窗口加了 `--mute-audio`，不会把直播间原声放出来盖住 AI 语音。
- 关闭软件时会顺带关掉这个浏览器窗口；勾了“断开时保留浏览器窗口”的话，手动断开不会关。

### 回复规则
每种事件独立设置：启用、AI/模板、模板（多行随机）、AI 提示。
模板变量：`{name}` `{text}` `{gift}` `{num}` `{value}` `{guard}` `{price}`。

弹幕额外可设：冷却秒数、回复概率、触发词、忽略表情包、先念原弹幕。
进房/关注/点赞可设：同人冷却、合并窗口、一次最多念几个名字。
礼物可设：连击合并、付费礼物最低价值、是否感谢免费礼物。
全局：屏蔽词、忽略名单、队列上限、最长等待、名字长度。
优先级：醒目留言 = 上舰 > 礼物 > 弹幕 = 关注 > 进房 > 点赞。

### 固定回复
弹幕命中关键词 → 直接念固定内容，不消耗 AI。

- 关键词逗号分隔；匹配方式：包含 / 完全一致 / 正则
- 回复每行一条随机选，可用 `{name}` `{text}`
- 可指定表情；从上到下匹配，命中第一条即停
- 不受回复概率/触发词限制；关掉弹幕 AI 回复也生效；仍受屏蔽词和冷却限制

### 点歌
观众先送点歌礼物拿券 → 发 `点歌:歌名` → 自动搜索网易云排队播放。
送插队礼物：排队中的歌立刻置顶；还没点歌则下一首点的歌直接置顶。
详情见 [README 的点歌一节](../README.md#点歌)。

**无人点歌时自动播放歌单**：先扫码登录网易云 →【点歌】页点“刷新歌单” → 选一个自己账号里的歌单 →
勾选“启用自动歌单”。可选随机/顺序；“有人点歌时立即切换”默认开启（点歌一来就切，播完自动回歌单）。

### AI 游戏
分“可互动”和“不可互动”两类，AI 会自己出题、接话、算分，语音和皮套表情照常走。

- **可互动**：猜数字（发数字，AI 提示大了小了）、数字炸弹（轮流报数缩小范围，踩中炸弹的人出局，
  其他人得逃生分）、抢答问答（第一个答对得 3 分）、词语接龙（用上一个词最后一个字开头）、
  观众投票（二选一发 1/2）、贪吃蛇（发 上/下/左/右 帮 AI 转向）、扫雷（发 `3,5` 翻第 3 行第 5 列）、
  2048（发 上/下/左/右 指挥，合出 64 以上新数字得分）、猜拳对决（发 石头/剪刀/布，赢 2 分平 1 分）、
  幸运抽奖（发 1 报名，倒计时抽 1~5 位，中奖 5 分）、飞花令（含令字的诗句，一句 1 分）
- **不可互动**：冷知识播报、故事连载《鲸鱼娘的海底电台》、脑筋急转弯、AI 讲笑话
- 每个游戏可单独勾“自动”，点“开始”手动开一局，“停止本局”立刻结束
- 自动轮换：只在连着直播间时生效；有人聊天时优先安排互动游戏，安静时播放单人节目；
  “每局之间间隔”控制频率（默认 180 秒）
- 猜数字最多提示次数、贪吃蛇速度、扫雷雷数、抽奖时长与中奖人数、AI 操作间隔可调；
  积分榜在本次运行中累计，可手动清空
- 观众发弹幕参与；游戏进行时其他聊天仍会正常回复（单人节目会暂时跳过普通弹幕，
  避免和节目抢话，礼物和 SC 不受影响）
- 贪吃蛇/扫雷/2048 是可视化小游戏：没人操作时 AI 自动继续，棋盘直接显示在 OBS 游戏面板里
- OBS 游戏面板：`/game`，背景透明，建议宽 760、高 700（显示小游戏棋盘）

### AI 设置
- Qoder：模型可一键列出并切换；会话常驻会记得上下文，“每多少句重开会话”控制记忆长度
- **接口模式**：Responses（默认，调 `/responses`）/ Chat Completions（调 `/chat/completions`）
  - 有些服务只支持其中一种；点【测试接口】会两种模式各发一个很小的请求，直接告诉你哪种可用并给出建议
  - 选 Responses 但接口不支持时，程序会自动改用 Chat Completions（本次运行记住，不再重复试）
  - 点 Z.ai / 智谱 / DeepSeek / 通义预设时会自动选 Chat Completions
- **思考程度**：跟随模型默认 / 关闭思考 / 低 / 中 / 高 / 自动
  - Qoder：启动时带 `--thinking` 或 `--reasoning-effort`
  - OpenAI 兼容接口：发 `reasoning_effort`，接口不认这个参数会自动去掉再试一次
  - ZCode：按等级发 thinking 预算；不支持时同样自动去掉重试
  - 外部 CLI：这个开关不生效，需要在 CLI 参数里自己控制
  - 改完下一条回复生效；Qoder 会话会自动重启
- 人设：决定主播性格与语气
- 每次回复最多字数：越短越快，直播建议 30~50

### 语音设置
启用语音、引擎目录/地址、GPT 与 SoVITS 权重、参考音频与文本、语言、
语速、表现力、采样步数（嫌慢改 16 或 8）、音量、输出设备。

### 固定话术烘焙
把固定台词先合成好存起来，之后播到这些台词直接读文件：

- 点【语音设置】最下方「一键烘焙固定话术」，进度和结果就在按钮下面
- 自动收集：游戏里的固定台词、回复模板 / 固定回复 / 点歌播报里不含变量的整句，以及
  带变量模板里的**固定片段**（约 100+ 条）
- **按变量拆段**（默认开）：`欢迎{name}来到直播间！` 这种会把「欢迎」「来到直播间！」读缓存，
  只现场合成名字，再把音频拼起来（拼接处 25ms 间隙）；觉得拼接感明显可以关掉这个开关
- 想加自己的台词：填在「额外固定话术」里，一行一条；带 `{name}` 的行会按模板拆段处理
- 缓存存在软件目录 `tts_cache/`，界面会显示已缓存多少条、占多少 MB
- 换了模型 / 参考音频 / 语速 / 采样步数后旧缓存失效，需要重新烘焙（界面会提示）
- 【清空缓存】可随时清掉；直播中也能烘焙，只是会慢一点，正常说话不受影响

### Live2D 皮套
- 模型目录与文件、大小与位置、呼吸、眨眼、头部摆动、口型与幅度
- 常驻表情（眼镜、发型等配件）
- 情绪 → 表情/动作映射表，所有表情动作都能一键试播
- 气泡：位置、字号、宽度、配色、停留时间

### OBS 字幕 / 点歌列表 / 游戏面板 / 本场数据
分别是 `/overlay`、`/songs`、`/game`、`/stats` 四个浏览器源地址。
`/stats` 的标题、位置、字号、显示项、礼物记录条数在【OBS 字幕】页最下方调整（约 5 秒内生效），
也支持 URL 参数：`/stats?fs=30&pos=top-right&rows=6`。

## 五、让观众听到声音

程序默认用系统默认扬声器播放。直播软件开启“电脑声音/桌面音频”采集即可。
如果你戴耳机而直播软件只采集麦克风，观众听不到；可安装虚拟声卡（如 VB-Cable）并在这里选择。

## 六、常见问题

**打开软件后直播间没连上、计时也不走？**
这是新版的开播总开关：默认不自动开始，点【控制台】顶部「开始」就会按设置连接、启动语音/歌单/游戏。
想打开就自动开始，勾上「打开软件时自动开始」。

**回复全是模板？**
看“AI 回复”里的来源与原因，多为 Qoder CLI 未登录 → 运行 `qoder_login.bat`。

**没声音？**
引擎是否“在线”、参考音频是否选、音量为 0、输出设备是否正确。

**观众名字是“新朋友”？**
未登录 B 站时名字被打码；扫码登录即可（也可在规则里关掉这个替换）。

**B 站登录显示无效？**
看控制台提示；`-101 账号未登录` 表示 Cookie 过期。手动粘贴时至少要有 `SESSDATA`。

**点歌放的不是原唱？**
原版无版权或需 VIP 时会找相似版本；登录网易云 VIP 后可放原版。

**歌太吵盖过说话？**
点歌页调小音乐音量，或把“说话时音乐压低到”调到 20%。

**关掉程序画面还留着？**
新版会自动隐藏（正常退出立即，强制结束 ≤5 秒）；仍残留就刷新直播软件里的浏览器源。

**游戏不自动开始？**
自动轮换要求“启用游戏”“自动轮换”都勾上，并且已经连接直播间；刚开播还要等“每局之间间隔”
倒计时。只想立刻看效果，就到【AI 游戏】点任意游戏的“开始”。

**观众发弹幕游戏没反应？**
猜数字要发 1~100 的数字；投票发 1/2；接龙要用当前提示的字开头。被忽略名单、屏蔽词命中的
观众不参与游戏；主播自己的弹幕也不会算。

**双击提示已在运行？**
程序只允许一个实例，会直接打开界面。彻底退出请点左下角“退出程序”，或直接关闭应用窗口。

**界面打不开 / 一片白？**
先看 `logs/app.log` 有没有 WebView2 相关报错。可以加启动参数 `--browser-ui` 用 Edge 窗口打开排查；
也可以运行 `config.json` 里的 `ui.native` 设为 `false` 长期改用浏览器窗口。

**想换直播间？**
【直播间 / 登录】改房间号 →“保存并重连”。

**抖音没有抓到弹幕？**
1）浏览器窗口里有没有登录抖音（没登录时抖音可能不显示弹幕）；2）页面里弹幕是否在滚动；
3）“抓取状态”里有没有报错；4）原始消息预览里出现“忽略”说明文本没认出来，把那一行发我加规则即可。
抖音改版频繁，抓取依赖页面结构，失效时优先更新软件。

**抖音的浏览器窗口被我关了？**
重新点“保存并连接”即可。窗口里的登录信息存在 `douyin_profile`，一般不用重新扫码。

**切换平台会丢设置吗？**
不会。B 站房间号、抖音房间号、回复规则、音色都是分开存的；切换只是换弹幕来源。

**想训练自己的音色？**
用 `tools/train_voice.py`（见 README）。

## 七、注意事项

- 只使用你有权使用的声音做参考音频，不要克隆他人声音；直播时建议说明是 AI 合成
- 点歌播放的音乐版权归权利人所有，公开播放需遵守平台规范
- `config.json` 里有登录 Cookie，不要发给别人
- 第三方组件与素材的许可见 [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md)
