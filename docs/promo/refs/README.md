# 角色参考图（本地素材，默认不提交到公开仓库）

这套图是给 AI 视频 / 绘画模型做「角色一致性」参考用的。三类来源，用途不同：

| 来源 | 文件 | 作用 |
|---|---|---|
| **Live2D 皮套实拍**（权威设计） | `01`~`05` | 1000px，正面 + 四种表情；画风、比例、配色以此为准 |
| **表情包抽帧**（情绪参考） | `06`~`13` | 256px，表情/情绪最丰富，只做「表情语气」参考，不要放大做特写 |
| **宣传封面**（构图参考） | `14`、`15` | AI 生成的构图版本，给模型看「氛围 + 排版」，造型仍以 01 为准 |

> 注意：`character-sheet.png` 是拼给人看的，**不要直接上传给模型**（会被当成一张多人物拼图）。

## 生成方式（可复现）

- Live2D 截图：运行鲸语 → 打开 `http://127.0.0.1:8787/live2d?bg=eef2f8` → 用 DevTools 协议截图；
  表情通过 `POST /api/l2d/test` 触发（设置页的「试播表情」按钮同源）。
- 表情包抽帧：取 `S:\jyn\鲸鲸.N.gif` 的中间帧导出 PNG。
- 封面：ImageGen 生成 + Pillow 排版（见 `docs/promo/video-brief.md`）。
